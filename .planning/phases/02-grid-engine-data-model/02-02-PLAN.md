<feature>
  <name>PuzzleGrid with shared-edge model and piece indexing</name>
  <files>crates/puzzle-core/src/grid.rs, crates/puzzle-core/src/piece.rs, crates/puzzle-core/src/lib.rs</files>
  <behavior>
    Given a valid PuzzleConfig, PuzzleGrid::new(config) produces a grid where:

    **Edge counts (shared-edge guarantee):**
    - h_edges has (rows+1) * cols elements
    - v_edges has rows * (cols+1) elements
    - Total internal edges = (rows-1)*cols + rows*(cols-1) for NxM grid
    - Total border edges = 2*rows + 2*cols
    - Total edges = h_edges.len() + v_edges.len()

    Test cases for edge counts:
    - 2x2: h_edges=4, v_edges=6 → total 10 (4 border, 1 h-internal, 1 v-internal... wait)
    - Actually: 2x2: h_edges = (2+1)*2 = 6, v_edges = 2*(2+1) = 6 → total 12
    - 3x4: h_edges = (3+1)*4 = 16, v_edges = 3*(4+1) = 15 → total 31
    - 6x8: h_edges = (6+1)*8 = 56, v_edges = 6*(8+1) = 54 → total 110

    **Edge coordinates:**
    - Cell width = config.width / cols, cell height = config.height / rows
    - h_edge at (row, col): start=(col*cell_w, row*cell_h), end=((col+1)*cell_w, row*cell_h)
    - v_edge at (row, col): start=(col*cell_w, row*cell_h), end=(col*cell_w, (row+1)*cell_h)

    **Border detection:**
    - h_edges at row=0 and row=rows → is_border=true
    - v_edges at col=0 and col=cols → is_border=true
    - All other edges → is_border=false

    **Tab direction (internal edges only):**
    - Assigned randomly using seeded ChaCha8Rng
    - Border edges: direction=In (unused but deterministic)
    - Same seed → same tab directions every time

    **Piece indexing:**
    - piece_at(row, col) returns PieceEdges { top, bottom, left, right } as indices
    - top = h_edges[row * cols + col]
    - bottom = h_edges[(row+1) * cols + col]
    - left = v_edges[row * (cols+1) + col]
    - right = v_edges[row * (cols+1) + (col+1)]
    - Adjacent pieces share exact same edge index (shared-edge proof)

    **Piece type classification:**
    - Corner: 2 border edges (4 pieces)
    - Edge: 1 border edge
    - Interior: 0 border edges
    - Matches compute_piece_breakdown counts exactly
  </behavior>
  <implementation>
    **grid.rs:**
    ```rust
    pub struct PuzzleGrid {
        pub config: PuzzleConfig,
        pub h_edges: Vec<Edge>,  // (rows+1) * cols
        pub v_edges: Vec<Edge>,  // rows * (cols+1)
    }

    impl PuzzleGrid {
        pub fn new(config: PuzzleConfig) -> Result<Self, String> {
            config.validate()?;
            let mut rng = create_rng(&config.seed);
            // Build edges with coordinates and tab directions
            // Border edges: is_border=true, direction=In
            // Internal edges: is_border=false, direction=random from RNG
            // RNG consumed in deterministic order: all h_edges row-major, then all v_edges row-major
        }

        pub fn h_edge(&self, row: usize, col: usize) -> &Edge
        pub fn v_edge(&self, row: usize, col: usize) -> &Edge
        pub fn piece_edges(&self, row: usize, col: usize) -> PieceEdges
        pub fn pieces(&self) -> Vec<Piece>
    }
    ```

    **piece.rs:**
    ```rust
    pub struct PieceEdges {
        pub top: usize,     // index into h_edges
        pub bottom: usize,  // index into h_edges
        pub left: usize,    // index into v_edges
        pub right: usize,   // index into v_edges
    }

    pub enum PieceType { Corner, Edge, Interior }

    pub struct Piece {
        pub row: usize,
        pub col: usize,
        pub piece_type: PieceType,
        pub edges: PieceEdges,
    }
    ```

    **lib.rs:** Add `pub mod grid;`, `pub mod piece;` and re-exports.

    RNG iteration order (CRITICAL for determinism):
    1. Iterate h_edges: row 0..=rows, col 0..cols — for each internal edge (row != 0 && row != rows), consume one rng.random_bool(0.5)
    2. Then iterate v_edges: row 0..rows, col 0..=cols — for each internal edge (col != 0 && col != cols), consume one rng.random_bool(0.5)
    This fixed order ensures seed reproducibility.
