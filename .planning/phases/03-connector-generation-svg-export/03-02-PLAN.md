<objective>
Build the SVG export pipeline that walks the puzzle grid, transforms edge-local connector curves to global coordinates, constructs a single SVG path with border + internal edges + rounded corners, applies optional kerf compensation, and exposes it via a WASM endpoint.

Purpose: This transforms the in-memory puzzle geometry into a production-ready file users can send directly to their laser cutter. The SVG must be correct on first export — laser cutter software is unforgiving with malformed SVG.

Output: `svg_export.rs` module, `kerf.rs` module, `kerf_width` config field, `generate_svg` WASM endpoint, complete laser-cutter-ready SVG output.
</objective>

**2. Create `kerf.rs`** — polyline offset for kerf compensation:
- `pub fn offset_path(path: &BezPath, kerf_width: f64) -> BezPath`
- If `kerf_width <= 0.0`, return a clone of the original path
- Flatten the path to line segments using `kurbo::flatten()` with tolerance 0.01 mm
- For each line segment, compute outward normal (perpendicular, left side for clockwise paths)
- Offset each segment's endpoints by `kerf_width / 2.0` along the normal
- Handle miter joins: compute intersection of adjacent offset segments; if miter ratio > 2.0, use bevel join
- Track subpath boundaries (MoveTo starts a new subpath; ClosePath closes it)
- Emit offset polyline as MoveTo + LineTo sequences (no re-smoothing for v1 per user decision)
- Add tests:
  - `test_zero_kerf_returns_original` — path unchanged with kerf=0.0
  - `test_positive_kerf_offsets_outward` — a simple square path becomes larger
  - `test_kerf_preserves_subpath_structure` — multiple subpaths remain separate

**3. Create `svg_export.rs`** — SVG path construction and document generation:
- `pub fn generate_svg(grid: &PuzzleGrid) -> String`
  - Calls `build_puzzle_path()` to construct a BezPath
  - If `grid.config.kerf_width > 0.0`, calls `offset_path(&path, grid.config.kerf_width)`
  - Calls `build_svg_document()` to wrap path data in SVG markup
  - Returns complete SVG string

- `fn build_puzzle_path(grid: &PuzzleGrid) -> BezPath`
  - Constructs a single BezPath with two groups:
  - **Group 1: Border (closed subpath)**
    - Walk the puzzle border clockwise: top→right→bottom→left
    - Top border: move_to(corner_radius, 0.0), then for each top h_edge: if internal edge intersects here, this is a border segment (line_to). Top h_edges are all border (straight lines), so emit line_to(edge.end.x, 0.0) for each, stopping short of corner_radius at the end
    - At each of the 4 corners, emit a quarter-circle arc using `kurbo::Arc` converted to cubic beziers via `arc.to_cubic_beziers()`. Corner arcs:
      - Top-right: center=(w-r, r), from angle -PI/2, sweep -PI/2 (clockwise)
      - Bottom-right: center=(w-r, h-r), from angle 0, sweep -PI/2
      - Bottom-left: center=(r, h-r), from angle PI/2, sweep -PI/2
      - Top-left: center=(r, r), from angle PI, sweep -PI/2
    - Between corners, emit straight line_to segments along the border
    - close_path() to close the border
  - **Group 2: Internal edges (open subpaths)**
    - For each internal h_edge (rows 1..rows, all cols): 
      - Transform connector curves from edge-local to global coords using `edge_transform(edge.start, edge.end)`
      - move_to(transformed first curve p0)
      - curve_to(p1, p2, p3) for each transformed curve
    - Same for each internal v_edge (all rows, cols 1..cols)
    - Shared edges appear exactly once (iterating the edge arrays directly, not per-piece)

- `fn edge_transform(start: Point, end: Point) -> Affine`
  - Compute angle from start to end: `angle = (end.y - start.y).atan2(end.x - start.x)`
  - Return `Affine::translate(start.to_vec2()) * Affine::rotate(angle)`

- `fn build_svg_document(path_data: &str, width_mm: f64, height_mm: f64) -> String`
  - Format: `<svg xmlns='http://www.w3.org/2000/svg' width='{w}mm' height='{h}mm' viewBox='0 0 {w} {h}'><path d='{path_data}' stroke='#000000' stroke-width='0.001mm' fill='none'/></svg>`
  - Per user decision: minimal SVG, no title/desc/metadata, single path element, absolute coordinates, inline stroke attributes

- Add `pub mod svg_export; pub mod kerf;` and `pub use svg_export::*; pub use kerf::*;` to lib.rs

Add tests:
