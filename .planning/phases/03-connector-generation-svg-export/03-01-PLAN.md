<objective>
Implement the ClassicKnobConnector that produces traditional Ravensburger-style knob shapes using cubic bezier curves, and wire it into PuzzleGrid so all internal edges get connector geometry.

Purpose: This is the core geometric algorithm that transforms a bare grid into a real jigsaw puzzle. Without connectors, pieces are just rectangles. The connector shapes determine whether laser-cut pieces interlock properly.

Output: `ClassicKnobConnector` struct implementing `ConnectorGenerator`, `PuzzleGrid::generate_connectors()` method, all internal edges populated with bezier curves.
</objective>

Implement `ClassicKnobConnector` in `classic_connector.rs`:

**generate() method:**
- Takes `EdgeParams` (length, direction, tab_size, jitter_amount) and `&mut ChaCha8Rng`
- Computes knob shape in edge-local coordinates (x: 0..length, y: 0 is baseline)
- Direction sign: `+1.0` for `TabDirection::Out`, `-1.0` for `TabDirection::In`
- Knob center: `length * 0.5 + center_jitter` where `center_jitter = jitter_amount * rng.random_range(-0.05..0.05) * length`
- Knob dimensions: `knob_w = length * tab_size`, `knob_h = knob_w * 1.2 * direction_sign`
- Neck dimensions: `neck_w = knob_w * 0.75` (narrower than body for snap-fit), `neck_h = knob_h * 0.35`
- Generate 4 control point jitter values: `cp_jitter[i] = jitter_amount * rng.random_range(-0.03..0.03) * length`
- Build 5 cubic bezier segments (per user decision: traditional rounded knob with visible neck):
  1. Baseline (0,0) → neck entry (left side)
  2. Neck → knob body (widening)
  3. Knob top (rounded bell curve)
  4. Knob body → neck (narrowing, mirror of segment 2)
  5. Neck exit → baseline (length, 0)
- Ensure first curve p0 == (0, 0) and last curve p3 == (length, 0) exactly (not computed)
- Ensure curve continuity: each p0 == previous p3

**validate() method:**
- Check that first p0 is at origin and last p3 is at (length, 0)
- Check all curves are continuous (gap < 1e-6)
- Check bounding box doesn't exceed 5% beyond nominal piece boundary (default from trait doc)

**generate_connectors() method on PuzzleGrid:**
- Create `ClassicKnobConnector` instance
- Use `create_rng(&self.config.seed)` for a fresh RNG (NOT the one from grid construction — separate deterministic sequence)
- Actually, reuse the grid's config seed but create a new RNG to avoid disrupting grid construction's RNG sequence
- Iterate through h_edges then v_edges (same row-major order as construction for determinism)
- For each edge: if `!is_border`, build `EdgeParams` from edge length + config tab/jitter, call `connector.generate(&params, &mut rng)`, set `edge.connector = Some(curves)`
- Border edges remain `connector: None`

Use `rand::Rng::random_range()` for jitter values (trait is `Rng` in rand 0.10, not `RngExt`). Import with `use rand::Rng;`.
