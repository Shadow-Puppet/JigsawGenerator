PuzzleConfig JSON shape (input to generate_svg):
```json
{
  "rows": 6, "cols": 8,
  "width": 297.0, "height": 210.0,
  "unit": "Millimeters",
  "tab": { "size_pct": 0.25 },
  "jitter": { "amount": 0.5 },
  "border": { "corner_radius": 2.0 },
  "seed": "my-seed",
  "kerf_width": 0.0
}
```

Defaults: rows=6, cols=8, width=297, height=210, unit=Millimeters, tab=0.25, jitter=0.5, corner_radius=2.0, seed="" (empty → "default" in WASM), kerf_width=0.0

Validation: rows/cols 2..100, width/height >0, tab 0.15..0.45, jitter 0.0..1.0, corner_radius 0.0..10.0, kerf 0.0..1.0

Unit enum values: "Millimeters" or "Inches"

Error detection: If response starts with "{" and contains "error" key, it's an error. SVG responses start with "<svg".

**SVG generation function:**
```typescript
function generatePuzzle(): void {
  const config = buildConfig();
  const configJson = JSON.stringify(config);

  // Generate SVG
  const svgResult = generate_svg(configJson);
  if (svgResult.startsWith("<svg")) {
    svgContainer.innerHTML = svgResult;
    errorDisplay.style.display = "none";
    // Also get piece breakdown
    const piecesResult = compute_pieces(configJson);
    const parsed = JSON.parse(piecesResult);
    if (!("error" in parsed)) {
      pieceCount.textContent = `${parsed.total} pieces (${parsed.corners} corner, ${parsed.edges} edge, ${parsed.interior} interior)`;
    }
  } else {
    // Error — keep previous SVG visible, show error message
    try {
      const err = JSON.parse(svgResult);
      errorDisplay.textContent = err.error || "Unknown error";
    } catch {
      errorDisplay.textContent = "SVG generation failed";
    }
    errorDisplay.style.display = "block";
  }
}
```

**Slider readout updater:**
For each slider (tab, jitter, radius, kerf), update the adjacent readout span on input. Format: tab shows percentage (e.g., "25%"), jitter shows decimal (e.g., "0.50"), radius shows value with unit (e.g., "2.0"), kerf shows value (e.g., "0.00").

**Event wiring (instant regeneration — NO debounce per user decision):**
- All number inputs: listen to "input" event → call generatePuzzle()

- Unit select: listen to "change" event → call generatePuzzle()
- Seed text input: listen to "input" event → call generatePuzzle()
- Randomize button: listen to "click" → set seedInput.value = randomSeed() → call generatePuzzle()

**main() async function:**

7. Wire all event listeners (as above)
8. Call generatePuzzle() for initial load — user sees a puzzle immediately

**Error handling:**

- SVG generation errors: show in error display below piece count, keep previous SVG visible
